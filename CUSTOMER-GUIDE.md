# 📱 How to Use ChatRewards

## What is ChatRewards?

Earn points every time you shop and redeem them for exclusive rewards — all through WhatsApp!

## Getting Started

1. **Save our WhatsApp number**: [Shop will add their number here]

2. **Send us a message**: Just say "hi" or "start"

3. **Shop and earn**: Every purchase earns you points automatically

## Commands

Send these messages to check your rewards:

### Check Your Balance
```
balance
```
or
```
points
```

### See Available Rewards
```
rewards
```

### Redeem a Reward
```
redeem [reward name]
```
Example:
```
redeem 10% discount
```

### Get Help
```
help
```

## How Points Work

- **Earn points** on every purchase
- **Get notified** instantly when you earn points
- **Unlock rewards** as you shop more
- **Redeem anytime** via WhatsApp

## Example

You buy something for **500 KES**:

1. ✅ You get a WhatsApp message:
   ```
   🎉 Payment confirmed!
   
   You earned +50 points!
   Amount: KES 500
   New balance: 150 points
   
   🎁 New reward unlocked: 10% discount!
   Reply "rewards" to see what you can redeem!
   ```

2. ✅ Check what you can redeem:
   ```
   rewards
   ```

3. ✅ Redeem when ready:
   ```
   redeem 10% discount
   ```
